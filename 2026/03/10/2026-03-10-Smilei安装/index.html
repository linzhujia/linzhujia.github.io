SMILEI 5.1 北京超算云（BSCC）安装指南（自装依赖版）

  • 仅使用 module load miniforge；其余依赖（编译器/MPI/并行 HDF5 等）全部在用户目录自装并固定版本。*

目标：避开不透明的 module load mpi/hdf5/python/gcc，把关键依赖安装到 $HOME/opt，做到可复现、可迁移。
系统假设：CentOS / SLURM。
重要提示：Smilei 的输入文件是 Python 脚本，运行时也需要 Python 环境；因此作业脚本里同样要激活同一个 miniforge 环境。

9. 常见问题排查（更新为自装依赖场景）

现象/报错 常见原因 解决方法
mpicxx 指向系统路径 PATH 没把自装 OpenMPI 放前面 export PATH=$OPT/openmpi-$OPENMPI_VER/bin:$PATH
h5pcc -showconfig 显示 Parallel HDF5: no 编译的是串行 HDF5 或没有用 mpicc 重新按 3.3 用 CC=mpicc + --enable-parallel 编译
运行时报 libmpi.so / libhdf5.so 找不到 LD_LIBRARY_PATH 未包含自装库 在作业脚本里补齐 OpenMPI/HDF5 的 LD_LIBRARY_PATH
make happi 或 import happi 失败 conda 环境缺包 mamba install -y numpy matplotlib h5py 后重试
Illegal instruction -march=native 在不同 CPU 节点不兼容 删除 -march=native，或用集群推荐架构标志
